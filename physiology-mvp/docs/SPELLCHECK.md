# Проверка русского текста

Дата проверки: 01.11.2026.

## Что проверялось

| Область | Файлы |
| --- | --- |
| Учебные материалы | `content/pilot/{muscle,tourism,topography}/{cards,questions,delayed_checks}.json` |
| Интерфейс | `apps/web/src/{App.tsx,content.ts,session.ts,types.ts}` |
| Оболочка | `apps/web/index.html`, `apps/web/public/manifest.webmanifest` |
| Документация | `docs/*.md`, `README.md`, `reviews/*.md` |
| Реестры и матрицы | `sources/*.csv`, `reviews/*.csv` |
| Сборка | `prototype.html`, корневой `index.html` |

Проверялись заголовки, тексты карточек, причинные цепочки, вопросы, варианты ответов, объяснения, подсказки, примечания об изменениях и подписи источников.

## Чем проверялось

- `tools/spellcheck.py` — словарь `ru_RU` из пакета Debian `hunspell-ru` через `spylls`. Неизвестные слова выводятся с контекстом; скрипт ничего не правит.
- `tools/spellcheck-allow.txt` — список проверенных вручную терминов, аббревиатур и имён собственных. Каждое слово просмотрено в контексте, а не добавлено для подавления предупреждения.
- `tools/check_grammar.py` — согласование предлогов, пробелы, дефис вместо тире, прямые кавычки, повторы слов, парность кавычек и скобок, единицы измерения без пробела.
- `tools/check_bundle_text.py` — дословное совпадение строк сборки с банками.
- Ручное чтение всех карточек, вопросов и вариантов ответов: словарная проверка не видит неверный порядок слов, неверное управление и неудачный термин.

## Результат

- Неизвестных слов: 0.
- Замечаний по грамматике и типографике: 0.
- Учебных строк в сборке: 1339, расхождений с банками: 0.
- Изменено элементов банков: 23 (физиология 11, туризм 9, топография 3), замен формулировок: 35. Ключи, идентификаторы, порядок вариантов, правильные ответы, лицензии, подписи источников и `review_status` не менялись.

## Что исправлено в учебных материалах

Орфография и словообразование:

- «пологче» → «пологий участок» (сравнительная степень от «пологий» не образуется так, как было написано);
- «выносливостная работа», «выносливостной работы» → «работа на выносливость»;
- «самоцельного повреждения» → «намеренного повреждения мышцы».

Согласование и пунктуация:

- «сердечная и гладкая мышца регулируются» → «сердечная и гладкая мышцы регулируются»;
- «Масштаб связан с степенью уменьшения» → «со степенью уменьшения»;
- «Восстановление часть адаптации» → «Восстановление — часть адаптации».

Порядок слов в вопросах: вопросительное слово поставлено в начало («Для чего особенно важны быстрые гликолитические волокна?», «На какой путь прежде всего опирается длительный бег низкой интенсивности?», «С каким изменением чаще связана силовая работа?» и другие).

Формулировки вариантов ответов и объяснений: убраны неточные обороты («при усталости или погоде», «Облегчение не должно убирать базовую навигацию», «Изменение маршрута требует актуализации информации», «Какое решение наиболее зрелое?», «дают мощность, но не долговечность»).

## Что исправлено вне учебных материалов

- `docs/ROADMAP.md`: «тяжёлая админка» → «сложная панель администратора».
- `docs/TEXT_STYLE.md`: «дисклеймеры о черновике» → «предупреждения о черновике».
- `docs/STATUS.md`: «поп-ап» → «окно», «скринридеру» → «программе чтения с экрана».
- `docs/PILOT_MODULE.md`: формулировка учебной цели приведена к «работе на выносливость».
- Редакторские матрицы: столбец `title_or_prompt` синхронизирован с банками. Прежняя версия подставляла в строки карточек текст отложенных проверок, потому что брала `card_id` вместо `question_id`. Синхронизация вынесена в `tools/sync_review_matrices.py`.

## Что оставлено без изменений

- Подписи лицензий и атрибуции, включая слово «футер» в описании источника МЧС: это указание на место размещения лицензии на сайте источника. Формулировку юридической подписи менять без необходимости не следует.
- Термины: «миофибрилла», «тропомиозин», «саркоплазматический ретикулум», «рекрутирование», «ресинтез», «скоростно-силовой».
- Определительные тире («Саркомер — участок миофибриллы…»): это норма русской пунктуации, а не признак сгенерированного текста.
- Оборот «источниковая база» в документации: принятый термин.

## Как повторить

```bash
bash tools/setup_spellcheck.sh
python tools/spellcheck.py
python tools/check_grammar.py
python tools/check_bundle_text.py
```

Правки стиля и орфографии банков заданы в `tools/style_pass.py` и применяются идемпотентно. Генератор новых предметов вызывает ту же обработку, поэтому повторная генерация не возвращает старые формулировки.

## Ограничение

Словарная проверка не заменяет предметную редактуру. Она подтверждает написание слов и оформление текста, но не достоверность фактов: туризм и топография остаются `draft`, расширенный банк физиологии не проверен предметным редактором.
