# Web-прототип

Редакторский прототип PWA для первого комплекта карточек. Материалы имеют статус `draft` и требуют предметной проверки.

## Запуск

```bash
cd physiology-mvp/apps/web
npm install
npm run dev
```

По умолчанию сервер слушает `0.0.0.0:5173`.

## Автономный просмотр без сервера

Из этого каталога выполните:

```bash
npm run build:standalone
```

Откройте созданный `../../prototype.html`. Все стили, код и материалы встроены в файл. Он подходит для встроенного просмотрщика с разрешённым JavaScript и заблокированной сетью. Прогресс в этой версии сохраняется только до закрытия или обновления страницы.

Не открывайте исходный `index.html` как статическую страницу: ему нужен Vite. После изменения исходников или контента повторите сборку.

## Проверки

```bash
npm run typecheck
npm test
npm run build
python ../../tools/validate_content.py
```

## Что реализовано

- теория → вопрос → обратная связь;
- первая ошибка не раскрывает правильный ответ;
- возврат к разбору и повторный вопрос;
- после повторной попытки показывается разбор;
- возможность продолжить после ошибки;
- очередь слабых тем;
- баллы активности отдельно от статуса освоения;
- локальное сохранение прогресса в IndexedDB;
- атрибуция источника на карточках и вопросах.

## Ограничения

- это не утверждённый учебный релиз;
- нет аккаунтов и серверной синхронизации;
- нет отложенных контрольных вопросов в UI;
- push-уведомления не реализованы;
- service worker регистрируется только в production-сборке;
- прогресс может быть удалён при очистке данных браузера.
