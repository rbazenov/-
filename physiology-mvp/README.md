# Учебные карточки — MVP

Учебная PWA для студентов физфака ЧГИФК: короткие карточки, вопросы, разбор ошибок и отложенное повторение.

## Предметы в прототипе

| Предмет | Модуль | Объём | Статус |
|---|---|---|---|
| Физиология человека | Физиология мышечной деятельности | 16 карточек / 48 тренировочных / 12 отложенных | смешанный: эталон approved со слов организатора, остальное draft |
| Основы спортивно-оздоровительного туризма | Безопасный учебный поход | 4 карточки / 12 тренировочных / 4 отложенных | draft |
| Топография и ориентирование на местности | Карта, рельеф, компас | 4 карточки / 12 тренировочных / 4 отложенных | draft |

Новые предметы добавлены как стартовые редакторские черновики. Утверждение физиологии на них не распространяется.

## Документы

- `docs/STATUS.md` — текущий статус и проверки.
- `docs/NEW_SUBJECTS.md` — новые предметы, источники и ограничения.
- `docs/ROADMAP.md` — этапы и критерии готовности.
- `docs/CONTENT_MODEL.md` — модель карточек и вопросов.
- `docs/EDITORIAL_REVIEW.md` — предметная проверка физиологии.
- `docs/TEXT_STYLE.md` — правила русского текста и скрипт стилевой правки.
- `docs/SPELLCHECK.md` — что проверено в русском тексте, что исправлено и чем.
- `reviews/NEW_SUBJECTS_BRIEF.md` — бриф проверки туризма и топографии.
- `sources/registry.csv` — реестр источников.
- `sources/pilot-chapters.csv` — главы/страницы и статус проверки.

## Открыть прототип

Откройте `prototype.html` в этом каталоге. Автономная версия работает во встроенном просмотрщике без сервера и интернета. На главной странице выберите предмет, затем «Начать». Корневой `index.html` рабочей области содержит такую же сборку для Preview project.

Исходники находятся в `apps/web/`. После их изменения пересоберите автономную версию командой `npm run build:standalone` из `apps/web/`.

## Проверки

- `python tools/style_pass.py` — правки стиля и орфографии в банках, идемпотентно.
- `python tools/validate_content.py` — структура, лицензии, статусы, длина текстов.
- `python tools/sync_review_matrices.py` — формулировки в редакторских матрицах.
- `bash tools/setup_spellcheck.sh` — модуль `spylls` и словарь `ru_RU` для проверки орфографии. Словарь берётся из Debian-пакета `hunspell-ru` (LGPL-2.1+), при недоступных apt-зеркалах — из npm-пакета `dictionary-ru` (BSD-3-Clause, тот же hunspell-словарь).
- `python tools/spellcheck.py` — орфография банков, интерфейса, документации и CSV.
- `python tools/check_grammar.py` — согласование, пробелы, тире, кавычки, скобки.
- `python tools/check_bundle_text.py` — совпадение строк сборки с банками.
- `cd apps/web && npm ci` — зависимости приложения.
- `cd apps/web && npm run typecheck && npm test -- --run && npm run build:standalone && npm run build`
- Браузерные сценарии в `tools/` (запускать из `.cache/preview-tools`, где установлен Playwright с браузерами): `test-mobile-grid.mjs` (сетка 2×2 на 320/360/390 px), `test-no-mixed-banner.mjs` (нет плашки о черновике, в шапке только «← Главная»), `test-subject-header.mjs` (описание на всю ширину, кнопка в шапке под баллами), `test-flat-screens.mjs` (учебные экраны без контейнера, окно возврата с подложкой), `test-swipe-hint.mjs` (жест-подсказка о свайпе: показ только новому пользователю, скрытие по таймеру и по касанию, reduced-motion), `test-option-ring.mjs` (скругление контейнеров ответа и переливающаяся рамка выбранного варианта), `test-page-scroll.mjs` (прокручивается страница, а не список: карточки уводят шапку вверх). Сценарии ждут проект по пути `/home/user/physiology-mvp`; при другом расположении поправьте `root` в скриптах.

Словарь и зависимости проверки живут в `.cache` и не входят в снимок рабочей области. После восстановления рабочей области выполните `bash tools/setup_spellcheck.sh`.

## Лицензии

Лицензия исходного кода приложения пока не выбрана. Лицензии учебных источников хранятся отдельно в реестре. Для новых предметов использованы материалы NPS/USGS с public-domain статусом и страницы МЧС с CC BY 4.0 в футере; российские вузовские пособия использованы только как тематический ориентир. Иллюстрации источников не встроены.
