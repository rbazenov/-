# BOXED.

Прототип витрины гастро-боксов: 6 готовых наборов, конструктор своего бокса,
корзина и оформление заказа.

**Сайт: https://rbazenov.github.io/-/**

- [`магазин/`](магазин/) — исходники витрины и инструкция по запуску
- [`магазин/boxed-standalone.html`](магазин/boxed-standalone.html) — вся витрина одним файлом

Демонстрационный проект: цены и остатки не являются публичной офертой.
