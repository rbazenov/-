# BOXED. — прототип нишевого интернет-магазина боксов

Рабочий прототип D2C-магазина авторских гастро-боксов: импортные сладости, азиатские снеки,
острая лапша и zero/протеиновые позиции. Продаём не «товар поштучно», а сценарий + сборку
и упаковку, средний чек 2 490–3 490 ₽.

## Как открыть в браузере

Локально, из папки `магазин`:

```bash
./serve.sh          # или: python3 -m http.server 8000 --bind 0.0.0.0
```

Затем открыть `http://localhost:8000/`.

### Публикация на GitHub Pages

В корне репозитория лежит `index.html`-редирект на `магазин/`, а в ветке — `.nojekyll`.
Pages настроен на ветку `main`, папку `/ (root)`. Сайт: https://rbazenov.github.io/-/

### Автономный файл

`boxed-standalone.html` — вся витрина одним файлом (CSS, JS и картинки внутри).
Открывается на телефоне без сервера и интернета.

## Что внутри

```
магазин/
├── index.html       витрина, конструктор, корпоративный блок, FAQ
├── css/style.css    тёмная тема, адаптив от 320 px, мобильная нижняя панель
├── js/catalog.js    данные: 6 боксов, 27 позиций конструктора, правила, промокоды
├── js/app.js        фильтры, карточка бокса, конструктор, корзина, оформление
├── assets/          изображения боксов
├── serve.sh         локальный запуск
└── boxed-standalone.html  автономная сборка
```

## Что работает

- **6 готовых боксов** с составом, весом, сроком годности и подсказкой «на сколько человек».
- **Конструктор** — 27 позиций с категориями, счётчиками и живым расчётом.
- **Корзина и оформление** — промокоды, бесплатная доставка от 2 500 ₽, три способа оплаты.
- **Мобильная версия** — 90% трафика с телефона: лента навигации, нижняя панель
  «Выбрать бокс / Корзина», полноэкранные карточка и оформление, тач-зоны 44–50 px,
  safe-area для iPhone, поля 16 px без зума в iOS.

## Важно

Всё работает в браузере: корзина и заказ хранятся локально, оплата не подключена.
Цены и остатки демонстрационные, публичной офертой не являются. Себестоимость,
маржа и условия поставщиков в публичный репозиторий не входят.
