# BOXED. — прототип нишевого интернет-магазина боксов

Рабочий прототип D2C-магазина авторских гастро-боксов: импортные сладости, азиатские снеки,
острая лапша и zero/протеиновые позиции. Продаём не «товар поштучно», а сценарий + сборку
и упаковку, средний чек 2 490–3 490 ₽.

## Как открыть в браузере

Локально, из папки `магазин`:

```bash
./serve.sh          # или: python3 -m http.server 8000 --bind 0.0.0.0
```

Затем открыть `http://localhost:8000/`.

### Публикация на GitHub Pages

В корне репозитория лежит `index.html`-редирект на `магазин/`, а в ветке — `.nojekyll`.
Pages настроен на ветку `main`, папку `/(root)`. Сайт: https://rbazenov.github.io/-/

## Автономный файл

`boxed-standalone.html` — вся витрина одним файлом (CSS, JS и картинки внутри).
Открывается на телефоне без сервера и интернета.

Файл **не редактируется руками**, он собирается из исходников:

```bash
./build.py           # пересобрать boxed-standalone.html
./build.py --check   # только сверить: не устарел ли файл (код возврата 1, если устарел)
```

Сборщик на Python 3 без зависимостей: вклеивает `css/style.css`, `js/catalog.js`, `js/app.js`
и переводит `assets/*.jpg` в base64. Абсолютные URL (`og:image`, `canonical`) он не трогает.
Итог — 1,45 МБ вместо 2,6 МБ у прежней ручной сборки.

## Что внутри

```
магазин/
├── index.html       витрина, конструктор, корпоративный блок, FAQ
├── css/style.css    тёмная тема, адаптив от 320 px, мобильная нижняя панель
├── js/catalog.js    данные: 6 боксов, 27 позиций конструктора, правила, промокоды
├── js/app.js        фильтры, карточка бокса, конструктор, корзина, оформление
├── assets/          изображения боксов (900×900, hero 1200×670, ~1,1 МБ всего)
├── build.py         сборка автономного файла
├── serve.sh         локальный запуск
├── tests/           проверки поведения в jsdom (npm test)
└── boxed-standalone.html  автономная сборка
```

## Что работает

- **6 готовых боксов** с составом, весом, сроком годности и подсказкой «на сколько человек».
- **Конструктор** — 27 позиций с категориями, счётчиками и живым расчётом: упаковка 190 ₽,
  скидка на объём от 7/10/14 позиций, лимиты по весу (2,2 кг) и напиткам (2 шт.).
- **Корзина и оформление** — промокоды, бесплатная доставка от 2 500 ₽, три способа получения
  и три способа оплаты. Доставка считается по способу: ПВЗ — 320 ₽ (бесплатно от 2 500 ₽),
  курьер — 320 + 290 ₽, самовывоз — всегда бесплатно.
- **Промокод запоминается** между перезагрузками (как и корзина), сбрасывается после заказа.
- **Мобильная версия** — 90% трафика с телефона: лента навигации, нижняя панель
  «Выбрать бокс / Корзина», полноэкранные карточка и оформление, тач-зоны 44–50 px,
  safe-area для iPhone, поля 16 px без зума в iOS.
- **Доступность** — skip-link, видимый фокус (`:focus-visible`), ловушка Tab в модалке и корзине,
  возврат фокуса на кнопку-источник, `aria-expanded` у FAQ и «показать ещё», `aria-pressed`
  у фильтров, подписи у всех полей и кнопок количества, `aria-live` у подсказок и тостов.
- **SEO** — абсолютные `canonical`/`og:image`/`twitter:image`, микроразметка Schema.org
  (`Organization`, `WebSite`, `ItemList` из 6 товаров, `FAQPage`), `width`/`height` у картинок,
  `fetchpriority="high"` на hero.

## Проверки

```bash
cd tests
npm install      # один раз: jsdom и axe-core, нужны только для проверок
npm test         # 59 проверок: корзина, промокод, доставка, конструктор, доступность, сборка
npm run a11y     # аудит разметки через axe-core
```

Тесты поднимают реальный DOM через jsdom и кликают по интерфейсу: проверяют суммы, сохранение
промокода, скрытые строки скидок, aria-атрибуты, возврат фокуса и актуальность
`boxed-standalone.html` (`build.py --check`). В самом сайте зависимостей нет — npm нужен
только для проверок.

## Изображения

Все картинки пережаты: боксы 900×900, hero 1200×670, JPEG q80, прогрессивный, без EXIF.
Было 1,6 МБ, стало 1,1 МБ. `assets/box-gamer.jpg` пока не используется ни в одном боксе —
оставлен как заготовка.

## Важно

Всё работает в браузере: корзина и заказ хранятся локально, оплата не подключена.
Цены и остатки демонстрационные, публичной офертой не являются. Себестоимость,
маржа и условия поставщиков в публичный репозиторий не входят.
